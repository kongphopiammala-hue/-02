# TITAN HOBBY & COLLECTIBLES 🚀
### เว็บไซต์ร้านขายโมเดลและฟิกเกอร์ระดับพรีเมียม (E-Commerce & Pre-order Platform)

โปรเจกต์ต้นแบบเว็บไซต์ร้านขายโมเดล ฟิกเกอร์ และ Art Toys ที่ออกแบบมาเพื่อตอบโจทย์นักสะสมโดยเฉพาะ โดยนำเทคนิคการตกแต่งและฟังก์ชันเฉพาะทางของวงการ Hobby มาใช้งานจริง

---

## 🌟 ฟีเจอร์เด่นที่ถูกพัฒนาขึ้น (Implemented Features)

### 1. การตกแต่งและบรรยากาศ (Design & Visuals)
- **ธีม Cyber-Mecha Dark Mode:** โทนสี ดำ-เทา-นีออนฟ้า-แดง ให้ความรู้สึกทันสมัย สไตล์โรงเก็บหุ่นยนต์และแกลเลอรีนักสะสม
- **Interactive 360° Turntable:** แท่นหมุนจำลองมุมมองโมเดล 3 มิติ สามารถคลิกลากเมาส์หมุนมุมมองได้รอบทิศ 360 องศา พร้อมปุ่มลัดเลือกมุมมองหน้า/ข้าง/หลัง
- **Hype & Urgency Countdown Timer:** นาฬิกานับถอยหลังรอบปิดรับจองพรีออเดอร์ (Pre-order Deadline) เพื่อกระตุ้นยอดขาย
- **Collector Scale Comparison:** แถบสเกลจำลองเปรียบเทียบขนาดจริง (เช่น เทียบความสูงกับขวดน้ำ/กระป๋อง) ช่วยให้นักสะสมประเมินขนาดพื้นที่ตู้โชว์ได้ง่าย

### 2. ระบบการขายเฉพาะทาง (Collector E-Commerce)
- **ระบบเลือกจ่ายมัดจำ (Deposit) vs จ่ายเต็มจำนวน (Full Payment):** รองรับระบบจองโมเดลล่วงหน้าที่มีความยืดหยุ่น
- **ป้ายกำกับสถานะสินค้า (Status Badges):** ระบุชัดเจน เช่น `PRE-ORDER`, `พร้อมส่งทันที`, `LIMITED EDITION`
- **ตัวกรองระดับนักสะสม (Collector Filters):**
  - กรองตามหมวดหมู่: Gunpla & Mecha, Scale Figures, Art Toys & Blind Box
  - กรองตามสเกล: 1/60 (PG), 1/100 (MG), 1/144 (RG/HG), 1/7, 1/6
  - กรองตามสถานะสินค้าและจัดเรียงราคา
  - ระบบ Live Search ค้นหาตามชื่อ, ซีรีส์ และค่ายผู้ผลิต

### 3. ประสบการณ์สั่งซื้อ (Shopping & Checkout Experience)
- **Shopping Cart Drawer:** ตระกร้าสินค้าแบบสไลด์ข้าง คำนวณยอดมัดจำและยอดรวมแยกกันชัดเจน
- **PromptPay QR Code Simulation:** ระบบจำลองขั้นตอนชำระเงินผ่าน Thai QR PromptPay พร้อมระบบตรวจจับและออกรหัสคำสั่งซื้อ (Order Tracking ID)
- **Collector's Hall of Fame (Community Showcase):** พื้นที่รีวิวสินค้าจริงจากตู้โชว์ของลูกค้าจริง สร้างความน่าเชื่อถือและความมั่นใจ

## 💻 วิธีการเปิดดูเว็บไซต์ (How to Run)

สามารถเปิดดูได้ง่ายๆ 2 วิธี:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์โดยตรง
- ดับเบิลคลิกที่ไฟล์ `index.html` ในโฟลเดอร์ `c:\งาน02` ผ่านเว็บบราวเซอร์ เช่น Google Chrome, Edge หรือ Firefox

### วิธีที่ 2: รันผ่าน Local Web Server (แนะนำ)
เปิด Terminal หรือ PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์:
```powershell
python -m http.server 8080
```
จากนั้นเปิดบราวเซอร์ไปที่: `http://localhost:8080`
